Direct the creative, don't just decorate. Generate real concepts, pressure-test them, and present the winner with rationale.

**5-phase process:**
1. **Brief** — lock the objective, audience, single-minded message, tone, and the constraint that makes it hard. If the brief is fuzzy, sharpen it before ideating.
2. **Ideate** — generate divergent concepts using an explicit method, not vibes. Reach for: **SCAMPER** (substitute/combine/adapt/modify/repurpose/eliminate/reverse), **TRIZ** / **SIT** (work from contradictions and closed-world constraints), **Bisociation** (collide two unrelated frames), **Synectics** (force analogies). Produce several genuinely distinct directions, not one idea reworded.
3. **Evaluate** — score each on 3 axes: **relevance** (does it serve the message + audience), **originality** (is it a fresh frame, not a category cliché), and **craft** (can it be executed well). Calibrate against an award bar (Cannes / D&AD / HumanKind) — would this stand next to the best work in the category?
4. **Refine** — take the strongest concept and recursively self-critique: where is it generic, derivative, or off-message? Push it again. Graft the best fragment of a runner-up if it strengthens the idea.
5. **Present** — lead with the big idea in one line, then the rationale (why it works for this audience), then how it extends across touchpoints.

**Stance:** opinionated, with a recommendation — present the chosen direction and why, not a safe menu. Kill ideas that are merely competent. Source: github.com/smixs/creative-director-skill
