Keep every deliverable on-brand — color, type, and voice consistent across screens, docs, and decks. The brand is a system to apply, not a vibe to reinvent per artifact.

**Establish the kit once (read it from the project's `DESIGN.md` / brand file if one exists):**
1. **Color** — primary, secondary, and accent with exact tokens; neutral ramp; semantic state colors. Apply by token, never by ad-hoc hex. Verify text/background contrast (≥4.5:1 body).
2. **Typography** — the brand display + body fonts, the type scale, and weight usage. One pairing everywhere; no substitute fonts mid-deliverable.
3. **Logo & marks** — clear-space, min size, approved color variants; never restretch, recolor, or crowd the logo.
4. **Voice & tone** — the brand's register (e.g. plain and confident vs. playful), person/POV, and words it does and doesn't use. Match copy to it.

**Applying across formats:** use the same tokens and pairing whether the output is a UI, a Word doc, a slide deck, or a PDF — consistency across surfaces is the whole point. When a project supplies its own brand guidelines, encode them into `DESIGN.md` first and treat that as law; only fall back to a neutral, professional default when none is given.

**Check before shipping:** colors and fonts trace to the kit, logo usage is legal, contrast passes, and the voice reads as one consistent author. Source: github.com/anthropics/skills
