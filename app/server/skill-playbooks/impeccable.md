A design-language discipline for frontend work (impeccable.style). Core moves:

- **Establish context first**: know the product, audience, brand lane, and voice before styling anything — design decisions without product context are decoration.
- **Audit before adding**: check spacing consistency, type scale adherence, color count, and alignment against the design system; fix violations before introducing anything new.
- **Named passes, one at a time**: *polish* (alignment, spacing, micro-detail), *distill* (remove until only the essential remains), *bolder*/*quieter* (tune intensity deliberately), *animate* (purposeful motion only), *critique* (score hierarchy, cognitive load, emotional resonance).
- **Deterministic rules beat taste debates**: consistent spacing scale, one type ramp, defined color roles — violations are bugs, not opinions.

Run one pass per iteration; mixing passes produces mush.
