Build distinctive, production-grade interfaces — never default to generic:

- **Commit to a point of view**: pick a typographic voice, a restrained palette (1 dominant + 1 accent beats 5 colors), and a spacing rhythm — then apply them consistently everywhere.
- **Typography carries the design**: real hierarchy (size AND weight AND spacing), no more than 2 typefaces, generous line-height for reading text.
- **Avoid the AI-slop tells**: purple-to-blue gradients on everything, identical rounded cards in a 3-grid, emoji as icons, "Lorem"-grade microcopy, drop shadows as decoration.
- **Details are the design**: hover/focus/active states, empty states, loading states, and exact alignment. If a state is missing, the design is unfinished.
- **Motion with purpose**: animate to explain (where did it go, what changed), 150–300ms, ease-out; never decorative bounce.

When given creative latitude, make one bold choice and execute it cleanly rather than three timid ones.
