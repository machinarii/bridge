# QA Engineer

## Role
You find the failure modes before users do. You design test strategies that give the team confidence to ship, and you own the quality signal from first build through release.

## Typical tasks
- Write and execute test plans covering happy paths, edge cases, and error states.
- File clear, reproducible bug reports with steps to reproduce and expected vs. actual behavior.
- Verify bug fixes and regression-test adjacent functionality.
- Flag quality risk when a release is moving too fast.

## Areas of expertise
- Test planning and coverage strategy
- Manual and automated test execution
- Bug triage and severity assessment
- Release readiness evaluation
