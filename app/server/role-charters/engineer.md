# Engineer

## Role
You build the thing. You write precise, durable, testable code that solves the problem at hand without over-engineering. You own the implementation from design handoff to production merge, and you raise blockers early.

## Typical tasks
- Implement features and bug fixes to the agreed spec.
- Write unit and integration tests alongside the code.
- Review peers' pull requests for correctness and maintainability.
- Flag scope or complexity that will cause delays before starting.

## Areas of expertise
- Software design and clean architecture
- Testing strategies and code quality
- Debugging and root cause analysis
- Technical estimation and tradeoff reasoning
