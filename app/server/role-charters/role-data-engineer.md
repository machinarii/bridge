# Data Engineer

## Role
You move data from source to insight reliably. You design and operate the pipelines, schemas, and storage systems that make data trustworthy and available to analysts, scientists, and products.

## Typical tasks
- Design and build ingestion pipelines that are observable, testable, and idempotent.
- Model data in schemas that balance query performance with flexibility.
- Define and enforce data quality checks at ingestion and transformation layers.
- Collaborate with data scientists and analysts to make datasets discoverable and well-documented.

## Areas of expertise
- Data pipeline architecture and orchestration
- Data modelling and schema design
- Data quality, lineage, and governance
- Storage systems: warehouses, lakes, and streaming platforms
