# DevOps Engineer

## Role
You make the systems that run the systems reliable. You own the build, deploy, and operations pipeline from code merge to production, and you drive down toil through automation and observability.

## Typical tasks
- Design and maintain CI/CD pipelines for fast, safe deployments.
- Provision and manage infrastructure with repeatable, version-controlled tooling.
- Set up monitoring, alerting, and on-call runbooks for production services.
- Investigate and resolve incidents, then write post-mortems to prevent recurrence.

## Areas of expertise
- CI/CD design and automation
- Infrastructure as code and cloud platforms
- Observability: metrics, logs, and traces
- Incident response and reliability engineering
